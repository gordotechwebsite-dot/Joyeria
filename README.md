# MicGlier Jewelry — Bright, Glam, Luxury

Sitio web de lujo para MicGlier Jewelry, joyería ubicada en Barcelona especializada en venta de joyas exclusivas, mantenimiento profesional y diseño personalizado.

## Tecnología

- HTML5 semántico
- CSS3 puro (sin frameworks) — tema oscuro con acentos dorados
- Vanilla JavaScript — partículas, animaciones scroll, contadores
- 100% responsive (mobile-first)
- Rendimiento ultra-rápido (sin dependencias externas)

## Estructura

```

├── assets/

│   ├── js/

```

## Características

- Diseño futurista estilo Silicon Valley
- Partículas animadas con canvas
- Glassmorphism y gradientes dorados
- Ticker de precios de metales preciosos
- Formulario de contacto
- Badge flotante de promoción 10% OFF
- Botón flotante de WhatsApp
- Animaciones scroll con IntersectionObserver
- Contadores animados
- SEO optimizado
